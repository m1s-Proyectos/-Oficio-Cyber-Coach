# Contenido educativo

Los escenarios y sus presentaciones viven como módulos TypeScript versionados. El catálogo no depende de servicios externos.

- `whatsapp-familiar`: suplantación de un familiar mediante una petición urgente.
- `tienda-iphone`: oferta comercial ficticia con señales de riesgo.
- `empleo-pago-previo`: oferta de trabajo que exige un pago anticipado.
- `codigo-verificacion`: solicitud indebida de un código de verificación.
- `supuesto-jefe`: suplantación de autoridad en el entorno laboral.
- `quickChallenges.ts`: ocho retos breves con pistas, señales de alerta, explicación y acciones seguras.

Todo el contenido es ficticio y se ejecuta en el navegador. No se solicitan datos reales ni se analizan mensajes de usuarios.
